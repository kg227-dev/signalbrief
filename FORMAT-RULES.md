# SignalBrief Format Rules
*Locked from Batch 1 feedback — Feb 28 2026*

## Item Format
```
[N]⃣ [TAG×TAG] Headline — one-liner strategic so-what
→ source.com
```

## Rules
1. **Number items** with keycap emojis: 1⃣ 2⃣ 3⃣ etc.
2. **Max 2 items per tag** — never stack same-tag items adjacently. Interleave topics.
3. **Links**: `→ domain.com` on same line or below, clean, no 🔗 emoji
4. **7 items default**, max 8
5. **Freshness signal**: add `(2d ago)` only when item is >24h old. Nothing if today.
6. **Every item must end with a strategic so-what** — one clause answering "why should a strategy consultant care about this tomorrow morning?" Make it explicit, not implicit.
7. **Cross-category tags** (×) are a feature — keep them. e.g. [AI×HEALTH], [PHARMA×M&A]
8. **Item length**: target ~2.5 lines on mobile. So-what must be tight — cut every word that doesn't add meaning. "Another payer going full care-delivery stack — point-solution vendors will feel it." not "Another payer becoming a care delivery stack; expect more point-solution vendors to get squeezed out of hospital contracts."
9. **Email CTA**: "📧 Deeper takes in your email" — signals email is expanded analysis, not a repeat

## Email-Specific Rules
1. **Quick-scan header**: 3-line TODAY'S SIGNALS summary before full items. 10-second read for time-pressed readers.
2. **Item length**: factual lede + 2-3 sentence "why it matters" = 4-5 sentences total per item. No more.
3. **Lead story**: mark item 1 as `★ LEAD` — gets the one item that can run 4-5 sentences analysis.
4. **Subject line**: date + 3 punchy topic teasers. e.g. "SignalBrief — Sat, Feb 28 | AI governance gap, Cigna's vertical play, FDA tightens"
5. **Footer**: include forward CTA, preferences, unsubscribe. "Forward to a colleague" is the growth vector.

## Header
```
☀️ SignalBrief — [Day, Mon DD]
```
Tagline: "Your daily signal across healthcare, AI, and strategy" — keep for now.

## Footer (2 lines max)
```
───
📧 Full digest in your inbox
💾 save [#] to bookmark · more/less [topic] to tune
```
