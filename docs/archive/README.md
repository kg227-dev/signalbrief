# Archive Policy

This directory holds historical docs that are kept for provenance, source material, and decision context.

Archive rules:

- keep historical docs readable and linked from an index
- do not treat archived docs as the primary source of truth
- move one-off campaigns, generated copy, and dated snapshots here once their durable guidance is captured elsewhere
- prefer adding a short historical note over heavily rewriting archived source material
