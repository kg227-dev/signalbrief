# Archive Policy

*Last reviewed: March 20, 2026*

This directory holds historical docs that are kept for provenance, source material, and decision context.

Archive rules:

- keep historical docs readable and linked from an index
- do not treat archived docs as the primary source of truth
- move closed plan bundles, dated snapshots, generated content, and one-off campaigns here once their durable guidance is captured elsewhere
- prefer adding a short archive note or README over heavily rewriting historical source material
