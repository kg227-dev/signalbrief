### Hypothesis: what is driving Day 22

1. **The calibration-window ranking gains mostly held.**
   Trust stayed high, fulfillment stayed full, and most lanes remained healthy.

2. **The immediate regression is a validator/parser issue, not retrieval depth.**
   The run had enough inventory and still lost two strong-tier writeups to **`validator_mismatch`**.

3. **Industrials still lacks a stable trusted floor.**
   When the lane is not protected tightly enough, it can still slide back toward standard-tier filler even with enough candidate depth.

4. **Expansion should wait for one more clean run after remediation.**
   The calibration window passed, but the latest live evidence is not clean enough to remove the block.

### Fix plan

1. **Repair the validator/parser mismatch path first.**
   Clear the two strong-tier writeup drops in Healthcare and Technology before making any expansion call.

2. **Then tighten Industrials source-mix and ranking floors.**
   The lane needs to stop falling below **3/5 trusted** when enough specialist inventory exists.

3. **Then keep tuning weaker-shape selection in Consumer & Retail.**
   The lane is acceptable, but it still leaves trusted stories behind when ranking gets loose.

4. **Keep category expansion blocked until a new clean live run lands.**
   The next run needs to restore **0 parse failures**, **0 strong-tier drops**, and a healthier Industrials basket.
