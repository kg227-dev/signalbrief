### Hypothesis: what's driving Day 9 results

1. **`provider_parse_failure` is now the primary system blocker, not topic scarcity.**
   40 of 69 drops cite this reason. The top-scored candidate in the entire run (0.984), the second-ranked Industrials story (0.984), and the top Healthcare miss all fail on the same root cause. This is not a scoring or selection problem — it is a content-parsing failure that the repair path cannot address.

2. **Source-monopoly is a second-tier failure mode that compounds the first.**
   When `provider_parse_failure` drops strong stories, the selector fills with whatever writes up successfully. If that pool is dominated by one source (marketwatch.com in FinServ, fda.gov in Life Sciences), those sources monopolize the final set even at low confidence scores.

3. **The repair pass is not functioning.**
   29 attempts, 0 recoveries, same as Day 8. The repair path is absorbing attempt budget with no return and should be treated as non-operational until root-caused.
