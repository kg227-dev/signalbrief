# Marketing Execution Playbook

*Last reviewed: March 20, 2026*

This is the canonical execution playbook for outreach, lifecycle messaging, community seeding, and content cadence. March 2026 source materials are archived under [`docs/archive/marketing/2026-03/`](../archive/marketing/2026-03/README.md).

Use [marketing-metrics.md](./marketing-metrics.md) as the live KPI snapshot and weekly review companion.

## Weekly Operating Cadence

Every week should cover four loops:

1. direct outreach to qualified prospects
2. product-adjacent content distribution
3. community participation without hard selling
4. follow-up with recent signups and lightly engaged readers

## Outreach

Priority channels:

- personal network by text or direct message
- warm LinkedIn DMs
- community-native posts after trust is established

Default outreach shape:

- make the audience fit explicit
- describe the product as a morning briefing, not a generic AI newsletter
- ask for a short trial and honest feedback
- follow up once after 48 hours, then stop

Minimum outreach tracker fields:

- name
- role or audience fit
- channel
- sent date
- follow-up date
- signed up
- feedback summary

## Lifecycle Messaging

Automated or semi-automated lifecycle messages should stay small and human.

Core trigger set:

- day-3 non-opener nudge
- day-8 pause warning
- day-11 auto-pause confirmation
- day-7 post-signup check-in
- testimonial ask after repeated opens
- 30-day winback for paused or churned readers

Message rules:

- lead with usefulness, not guilt
- offer concrete fixes: topics, time, depth, or pause
- keep personal asks distinct from system-generated emails
- prefer a reply invitation over a long CTA list

## Community Seeding

Rules:

- value first, product mention second
- earn trust before posting direct asks
- use communities that match the actual ICP
- do not post product links into communities that have not yet seen useful contributions

Best-fit channels from the current source material:

- `r/consulting`
- `r/MBA`
- `r/FinancialCareers`
- private consulting and finance communities where trust already exists

## LinkedIn And Public Content

Default cadence:

- three LinkedIn posts per week
- use a real signal or public digest example whenever possible
- alternate between pain-first, demo-in-public, and referral/social-proof formats

Content rules:

- specific beats generic
- one concrete example beats abstract product claims
- end with a clear but low-friction CTA
- reuse public digest pages as proof, not just as promotion

## Execution Guardrails

- keep a single source of truth for messaging in this file and [`marketing-strategy.md`](./marketing-strategy.md)
- archive dated campaigns and generated copy instead of letting them accumulate as active docs
- update the tracker and KPI review weekly using [`marketing-metrics.md`](./marketing-metrics.md)
- stop channels that create signups without retained opens
