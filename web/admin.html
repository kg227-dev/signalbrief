How to read this
Run Metrics
Users is recipients actually served in that run. Tokens is Claude input/output usage. Total is API spend for the run: Perplexity plus Claude.
Digest Quality
This is a whole-brief score from 0 to 100. It rewards topic fit, ranking quality, analysis quality, freshness/diversity, and custom-topic coverage.
topic = topic fit rank = ranking quality analysis = writeup quality fresh = novelty + diversity custom = custom-topic coverage
Debug Chips
Inside each run, signal is the item score, strategic is business importance, routine is low-value/routine risk, and dup / sat are duplication and entity-saturation penalties.
novelty = new vs recent history source = source authority story = storyline cluster entity = extracted company/topic
